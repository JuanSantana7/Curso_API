# API de Cursos
APi para gerenciar de professores e cursos

## tecnologias
-JavaScript
-node
-mysql
-Express

## Endpoints
- `POST / professores` - criar um professor
- `GET /professores` - Lista professores -
- `POST / Cursos` - criar um cursos
- `GET / cursos/` - Lista cursos
- `DELETE / cursos/:id` - delete um curso por id
